# Veritas - Versao 1.2.0

Esta versao traz melhorias importantes no atualizador, na experiencia de leitura e na organizacao das colecoes pessoais.

## Novidades

- Adicionada a opcao de compartilhar as Palavras do Papa.
- Adicionado suporte a pastas para notas.
- Implementadas as funcionalidades de criacao, exclusao e movimentacao de notas entre pastas.
- Adicionada a exclusao de pastas com confirmacao.
- O nome da area "Notas" foi alterado para "Colecoes".

## Correcoes e melhorias

- Corrigido e revisado o auto-update para instalar corretamente novas versoes do aplicativo.
- Adicionada a verificacao de permissoes a cada novo update.
- Corrigido o icone do aplicativo para se adaptar melhor a diferentes dispositivos.
- Corrigido um bug na Liturgia Diaria que exibia os santos do dia de forma incorreta.
- Ajustados o tamanho das notas e o layout do modulo de colecoes.

## Atualizacao tecnica

- Projeto atualizado completamente do Expo SDK 54 para o Expo SDK 57.
- Adicionada automacao para informacoes do projeto.
